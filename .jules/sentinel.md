## 2023-10-27 - [Path Traversal & UI Spoofing in Filename Sanitization]
**Vulnerability:** The existing filename sanitization in `FrameExporter.kt` failed to strip Unicode BIDI and formatting characters (`\p{Cc}\p{Cn}\p{Cf}`) and did not collapse multiple consecutive underscores when converting malicious characters, potentially enabling Right-To-Left Override (RLO) UI spoofing attacks where dangerous file extensions (like `.exe`) are made to appear as safe ones (like `.jpg`), alongside hidden empty-name files.
**Learning:** Using basic ASCII-only blocklists for sanitizing user-provided filenames is insufficient. Android implementations must defend against Unicode-based spoofing on exported files that users will interact with.
**Prevention:** Always use comprehensive Unicode property classes (e.g., `\p{Cc}\p{Cn}\p{Cf}`) alongside standard filesystem invalid characters (`[\\/:*?"<>|]`) when cleaning strings used for file outputs. Additionally, sanitize consecutive underscore outputs to prevent overly long or visually hidden path outputs.
